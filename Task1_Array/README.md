# Task 1: Exploration of Array and ArrayList (Pages 26-31)

This folder contains the implementation of the `Account`, `Customer`, and `Bank` classes as requested on pages 26-31 of the OOP material.
A `MainBank` class is also included to demonstrate the interactions with an interactive CLI menu (ATM-like) using `java.util.Scanner`.

## How to compile and run
```bash
javac *.java
java MainBank
```
